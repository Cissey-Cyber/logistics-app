Route optimization API

POST a list of stops with latitude and longitude to /routes/optimize. The service returns a nearest-neighbour stop order and estimated straight-line distance.

curl -X POST http://127.0.0.1:5000/routes/optimize \
  -H "Content-Type: application/json" \
  -d '{"start":{"lat":12.00,"lon":8.52},"stops":[{"name":"Stop A","lat":12.01,"lon":8.53},{"name":"Stop B","lat":12.04,"lon":8.50}]}'
